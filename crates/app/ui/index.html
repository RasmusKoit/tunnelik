    No tunnel selected

    Add a tunnel by pasting a WireGuard config, or importing a .conf file. Then connect it here, from Settings › Network & internet › VPN, or with tunnelik up <name>.

    Interface:

    Holds off the idle sleep timer while more than about 64 KiB a minute goes through the tunnel. Closing the lid or pressing the power button still works.

    Windows brings the tunnel back after standby or a network change. Turning it off here, in Settings or from the flyout keeps it off until the next sign-in or network change.

    Start on its own

    Windows connects this tunnel when one of these programs starts, or when one of these domains, or a name under one, is looked up. It watches names, not addresses or subnets, and names under these domains are resolved through the tunnel's DNS. Windows watches for one tunnel at a time; after you disconnect it yourself, it waits for the next network change or sign-in before starting it again. Changing this list rebuilds the tunnel's VPN connection, reconnecting it afterwards if it was up.

    Starts Tunnelik's helper service, which keeps such a tunnel's profile system-wide, until you turn it off or restart the PC. Windows asks for administrator approval.

        Tunnelik itself connects this tunnel when a program first tries to reach one of these ranges. It sees TCP connections only; ping and UDP do not count. The attempt that starts the tunnel still fails, the program's next try goes through. After you disconnect the tunnel yourself it stays down for ten minutes.
